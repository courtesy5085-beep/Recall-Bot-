# 🧠 RecallBot

**RecallBot** is an AI-powered memory assistant for team chats. Upload your WhatsApp (`.txt`) or Slack (`.json` / `.zip`) exports, and ask natural-language questions about your conversations. Answers are generated by **GPT-4o-mini** with exact cited source messages.

![Python](https://img.shields.io/badge/python-3.11-blue) ![Streamlit](https://img.shields.io/badge/streamlit-1.39-red) ![License](https://img.shields.io/badge/license-MIT-green)

---

## ✨ Features

- 🔐 **Authentication** — secure signup/login with hashed passwords
- 💬 **Chat Import** — WhatsApp `.txt` and Slack `.json` / `.zip` exports
- 🧬 **Vector Memory** — ChromaDB + Sentence Transformers embeddings
- 🤖 **AI Q&A** — streaming GPT-4o-mini answers with citations
- 🔎 **Advanced Search** — semantic + keyword, date / user filters
- 📊 **Analytics Dashboard** — Plotly charts, heatmaps, top keywords
- 🔖 **Memory Tools** — bookmarks, saved queries, AI summaries, tags
- 🎨 **Premium UI** — glassmorphism, neon gradients, dark/light mode

## 🚀 Quick Start (Local)

```bash
git clone https://github.com/yourname/recallbot.git
cd recallbot
pip install -r requirements.txt
echo "OPENAI_API_KEY=sk-..." > .env
streamlit run app.py
```

Open <http://localhost:8501>.

---

## ☁️ Deploy on Streamlit Cloud

1. Push this repo to **GitHub**.
2. Go to <https://share.streamlit.io> → **New app**.
3. Select your repo / branch / `app.py`.
4. Under **Advanced settings → Secrets**, add:

   ```toml
   OPENAI_API_KEY = "sk-..."
   ```

5. Click **Deploy**. Done. 🎉

## 🧪 Usage

1. **Sign up** with any email + password.
2. **Upload** WhatsApp / Slack exports in the sidebar.
3. Wait for **indexing** (progress shown live).
4. Ask questions in the **Chat** tab — answers stream with citations.
5. Explore the **Analytics** and **Search** tabs.

### Example prompts

- *"What did Ahmed say about the budget?"*
- *"Summarize last week's discussion."*
- *"Find all action items mentioned."*
- *"Who mentioned the API bug?"*

## 📦 Tech Stack

Python 3.11 · Streamlit · OpenAI GPT-4o-mini · ChromaDB · Sentence Transformers · LangChain text splitters · SQLite · Plotly · Pandas · tiktoken

---

## 🔒 Security

- Passwords hashed with PBKDF2-SHA256 + per-user salt
- API keys loaded only from environment / Streamlit secrets
- File-type & size validation on every upload
- User data isolated per account in SQLite + ChromaDB collection
